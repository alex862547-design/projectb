# SQL init scripts (สำหรับ Docker เท่านั้น)

ไฟล์เหล่านี้เป็นสำเนาของไฟล์ใน `server/sql/` ตั้งชื่อใหม่ให้มีเลขนำหน้าตามลำดับที่ต้องรันจริง
(PostgreSQL image จะรันไฟล์ในโฟลเดอร์นี้ตามชื่อ เรียงตัวอักษร ตอน container ฐานข้อมูลเริ่มทำงานครั้งแรกเท่านั้น)

**ไม่ได้รวม `checkin_permission_migration.sql`** เพราะคอลัมน์ `can_checkin` ที่มันสร้าง ถูกรวมเข้าไปใน `schema.sql`
อยู่แล้วตั้งแต่ต้น — รันซ้ำจะ error "column already exists"

ถ้าแก้ไฟล์ต้นฉบับใน `server/sql/` แล้ว ต้อง copy มาอัปเดตไฟล์ในนี้ด้วย (ไม่ได้ลิงก์กันอัตโนมัติ)
